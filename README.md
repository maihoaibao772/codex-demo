# mahiiruu_

A modern creative portfolio experience infused with dark synthwave gradients, smooth parallax motion, and playful randomness. Built with Vite + React + TypeScript + Tailwind CSS + Framer Motion + shadcn-inspired components.

## Getting started

```bash
npm install
npm run dev
```

Development server defaults to [http://localhost:5173](http://localhost:5173).

### Production build

```bash
npm run build
```

Preview the production output with `npm run preview`.

## Customization

- **Gallery images:** Update the array in [`src/components/Gallery.tsx`](src/components/Gallery.tsx) with your own image URLs and captions to instantly reskin the showcase.
- **Quotes list:** Edit [`src/data/quotes.ts`](src/data/quotes.ts) to add, remove, or rewrite the rotating surreal quotes.
- **Theme + animations:** Tailwind lives in [`tailwind.config.ts`](tailwind.config.ts) where the neon gradient palette, glow shadows, and custom animations are defined. Adjust values or add new keyframes to reshape the vibe.

## Stack highlights

- Vite + React + TypeScript for a fast, strongly typed foundation.
- Tailwind CSS for expressive styling with a neon `from-indigo-500 via-purple-500 to-pink-500` gradient theme.
- Framer Motion drives hero particles, scroll fades, parallax gallery, and interactive quote transitions.
- Shadcn-inspired utility components (powered by `class-variance-authority`) keep UI elements cohesive and reusable.

Enjoy the chaos-crafted portfolio! 🚀
