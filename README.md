# mahiiruu_ Ultra Edition

A neon-drenched creative playground powered by React, Vite, TypeScript, TailwindCSS, Framer Motion, Three.js, and shadcn-inspired UI accents. Every interaction glows, every scroll unveils a new layer of chaos-crafted imagination.

## ✨ Getting Started

```bash
npm install
npm run dev
```

Visit the printed local URL (default `http://localhost:5173`) to explore the experience.

## 🛠️ Customize the Vibes

- **Sections** – Edit the components under `src/components/` to tweak layout, copy, or animations. Each section is self-contained and wrapped with Tailwind utility classes for effortless iteration.
- **Quotes** – Update or expand the list at `src/data/quotes.ts`. The quote rotator automatically picks a new line at runtime.
- **Styling** – Tailwind theme extensions live in `tailwind.config.ts`. Adjust the neon palette, add gradients, or tweak animations. Global styles and background gradients are defined in `src/styles.css`.

## 📦 Tech Stack

- React + Vite + TypeScript
- TailwindCSS + ShadCN UI primitives
- Framer Motion + Three.js + @react-three/fiber/drei
- Lucide React icons and class-variance-authority helpers

## ♻️ Zero Binary/Audio Assets

The entire project is code-only. All visuals rely on CSS, SVG, procedural canvas animations, or remote Unsplash imagery—no bundled binaries or audio files.

## ✅ Performance Goals

- Smooth 60fps animations for hero 3D scene, particles, and cursor glow
- Responsive layout across mobile, tablet, and desktop breakpoints
- Lighthouse Performance ≥ 90 with lazy-loaded assets and optimized transitions

Dive in, remix, and keep the neon humming.
